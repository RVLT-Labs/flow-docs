# Glossary

The words Flow uses, in the order you'll meet them. UI labels are bold —
these are the exact terms on screen.

:::note[🚧 Growing]
This glossary is seeded with the core vocabulary; terms get added as the
guide's sections are written.
:::

| Term | Meaning |
|---|---|
| **Model** | The equipment type/spec — "Shure SM58" — with its photo and rental rates. Not a physical unit. |
| **Asset** | One physical, serialised unit of a model, with its own tag, status, and history. |
| **Bulk stock** | Counted-quantity gear with no individual identity — leads, sandbags, clamps. |
| **Kit** | A container of gear that travels and prices as one unit. |
| **Accessory** | Gear attached to other gear — permanently (child asset) or by default/option on a model. |
| **Project** | A job: client, dates, gear list, crew, documents. |
| **Line item** | One row on a project's gear list — a model, kit, sub-hire, sale, or custom item. |
| **Group** | A named section of a project's gear list; can carry its own pricing and discount. |
| **Client** | The renting party — always "client" in Flow, never "customer". |
| **Supplier** | A vendor you buy from or sub-hire gear from. |
| **Sub-hire** | Gear rented in from a supplier to cover a job — tracked with both its cost and its charge. |
| **Deploy** | Gear checked **out** of the warehouse onto a job. |
| **Return** | Gear checked back **in** from a job. |
| **Prep** | A staging label grouping gear into a case/container during picking. |
| **Pick slip** | The warehouse document listing what to pull for a job (also called a packing list or pull slip). |
| **Delivery docket** | The document that travels with the gear to site. |
| **Return sheet** | The document listing what should come back from a job. |
| **Check item** | A pass/fail, measurement, or notes quality check run on gear at deploy or return. |
| **Test & Tag (T&T)** | AS/NZS 3760 electrical safety testing and its records. |
| **Overbooking** | More gear promised over a date range than you own (after sub-hires). |
| **Pencilled** | A tentative booking — visible on the schedule as risk, not yet a hard commitment. |
| **Quote** | The priced offer sent to a client — frozen when sent; changes make a new version. |
| **Invoice** | The issued bill — immutable once issued; corrections void and reissue. |
| **Unlock session** | A justified, audited window in which a confirmed job's protected fields may be edited. |
| **Crew** | A person who can be scheduled onto job work — with or without a Flow login. |
| **Member** | A user account inside your org, with a role. |
| **Mira** | Flow's built-in assistant — answers questions as you, read-only. |
