# The rental workflow

Every job in Flow runs the same spine: **enquiry → project → quote →
confirmation → prep → deploy → on site → return → close-out → invoice**.
This section walks that spine once, in order, in plain language — every
module in the app hangs off one of these steps, and each chapter links into
the detailed guides.
