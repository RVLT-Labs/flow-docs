# How quotes and invoicing work

Two documents carry the money: the **quote** (the offer) and the **invoice**
(the bill). Both follow one rule that explains most of this section's
behaviour: once a document has been in front of a client, it never silently
changes. New numbers mean a new version or a new document — never an edit
to the one they're holding.
